# ICD自动编码系统 - 微服务端口分配表

## 📋 端口映射总览

| 端口范围 | 用途 | 说明 |
|---------|------|------|
| 8000-8099 | 核心业务服务 | 后端API、网关、模型服务 |
| 8100-8199 | 前端与UI服务 | Web界面、管理后台 |
| 8200-8299 | 数据存储服务 | 数据库、缓存、消息队列 |
| 8300-8399 | AI/ML服务 | 大小模型推理、向量库 |
| 8400-8499 | 监控与运维 | 日志、指标、追踪 |

---

## 🚀 核心业务服务 (8000-8099)

| 端口 | 服务名称 | 路径前缀 | 说明 | 状态 |
|------|---------|---------|------|------|
| **8000** | API Gateway / 主后端 | `/api` | FastAPI主服务，统一API入口 | ✅ 已实现 |
| **8001** | 认证服务 (Auth) | `/api/auth` | JWT鉴权、用户管理、RBAC | ❌ 待实现 |
| **8002** | 工作流引擎 (Workflow) | `/api/workflow` | 病历状态流转、任务调度 | ⚠️ 部分实现 |
| **8003** | 模型调度中心 (Dispatcher) | `/api/dispatch` | 大小模型路由、负载均衡 | ❌ 待实现 |
| **8004** | 审核与日志服务 | `/api/audit` | 操作日志、修改记录、审计 | ❌ 待实现 |
| **8005** | 小模型服务 (ML Models) | `/api/models` | 轻量级ICD编码推理服务 | ✅ 已规划 |
